# **Telegram bot для проведения анкетирования**

Данный Telegram бот создан для проведения анкетирования или опросов пользователй.
Что умеет: 

* Можно подгружать вопросы из таблицы Excel
* Просматривать статискику по прохождению анкетирования
* Назначать/удалять администраторов бота.
* Получать отчет по результатам анкетирования в формате Excel
* Пользователи получают свои анкеты с результатами в формате PDF
* Загружать свои логотипы для анкеты

Поддерживается следующий формат таблицы Excel с вопросами:

Первая колонка (A) - **тип** может принимать следующие значения:

**header**\
  (Колонка B): любой текст, выводится как сообщение пользователю один раз в самом начале.\
  (Колонка C): Имя файла с изображением, если заполнена то текст будет выведен как подпись к изображению\
  остальные колонки игнорируются

**text**\
  (Колонка B): любой текст, выводится как сообщение пользователю. Не подразумевает никаких действий со стороны пользователя

**simple**\
  (Колонка B): любой текст, выводится как вопрос. Ожидает ответа пользователя путем ввода и отправки сообщения.\
  остальные колонки игнорируются 

**onlyone**\
  (Колонка B-Z..): любой текст, выводится как меню из кнопок. Возможен единственный выбор.

**select**\
  (Колонка B-Z..): любой текст, выводится как меню из кнопок. Возможен множественный выбор.

**footer**\
  (Колонка B): любой текст, выводится как сообщение пользователю один раз в конце, после ответа на последний вопрос.\
  (Колонка C): Имя файла с изображением, если заполнена то текст будет выведен как подпись к изображению\
  остальные колонки игнорируются 

**report**\
  (Колонка B): любой текст, выводится как заголовок в отчете пользователя при генерации PDF отчета.\
  (Колонка C): Имя файла с изображением, если заполнена выводится как логотип в отчете пользователя при генерации PDF отчета.\
  остальные колонки игнорируются\

**Пример**

|    A    |                     B                      |         C          |      D       |          E          |
| :-----: | :----------------------------------------: | :----------------: | :----------: | :-----------------: |
| header  | Ответьте пожалуйста на несколько вопросов: |     logo.jpeg      |              |                     |
|  text   |                Первый блок                 |                    |              |                     |
| simple  |               Имя и фамилия                |                    |              |                     |
| onlyone |              Сколько Вам лет?              |       15-25        |    26-50     |       51-100        |
|  text   |                Второй блок                 |                    |              |                     |
| select  |           Что вам сейчас важнее?           |    Убрать боль     | Наладить сон | Снизить тревожность |
| footer  |  Поздравляем! Вы ответили на все вопросы.  | congratulation.jpg |              |                     |
| report  |                   Анкета                   |     logo.jpeg      |              |                     |


**ВНИМАНИЕ! При загрузке новых вопросов: текущие вопросы и ответы будут удалены!**

* После ответа на последний вопрос, пользователю направляется его личный отчет в формате PDF. 

* Администратор может выгрузить результаты по всем пользователям в Excel формате.
